Política de Privacidade

Última atualização: 15 de abril de 2025

Esta Política de Privacidade descreve como o AtendiBot coleta, usa e protege as informações dos usuários ao utilizar nossos serviços de atendimento automatizado via WhatsApp.

1. Informações que coletamos

Ao interagir com o AtendiBot via WhatsApp, podemos coletar:

  • Número de telefone do usuário
  • Nome fornecido pelo usuário durante a conversa
  • Data e horário das mensagens trocadas
  • Informações de agendamento (data, horário, serviço solicitado)

2. Como usamos as informações

As informações coletadas são utilizadas exclusivamente para:

  • Realizar e confirmar agendamentos solicitados pelo usuário
  • Enviar lembretes e confirmações via WhatsApp
  • Melhorar a qualidade do atendimento automatizado

3. Compartilhamento de dados

O AtendiBot não vende, aluga ou compartilha suas informações pessoais com terceiros, exceto quando necessário para a prestação do serviço (como integração com a API do WhatsApp Business da Meta) ou quando exigido por lei.

4. API do WhatsApp (Meta)

Este serviço utiliza a API oficial do WhatsApp Business, fornecida pela Meta Platforms, Inc. O uso dessa API está sujeito aos Termos de Serviço do WhatsApp e à Política de Privacidade da Meta.

5. Retenção de dados

As informações são armazenadas pelo tempo necessário para a prestação do serviço e cumprimento de obrigações legais. O usuário pode solicitar a exclusão de seus dados a qualquer momento.

6. Direitos do usuário

O usuário tem direito a:

  • Acessar os dados que possuímos sobre ele
  • Solicitar a correção de dados incorretos
  • Solicitar a exclusão de seus dados
  • Revogar o consentimento para uso dos dados

7. Segurança

Adotamos medidas técnicas e organizacionais adequadas para proteger suas informações contra acesso não autorizado, perda ou divulgação indevida.

8. Contato

Para dúvidas, solicitações ou exercício de direitos relacionados a esta política, entre em contato pelo e-mail: contato@atendibot.com
